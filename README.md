# GPA Calculator · 绩点计算器（Web 版）

北理工 4 分制绩点估算工具，纯前端（HTML + CSS + JavaScript），无后端、无依赖，打开即用。

**在线访问：https://gpacalc.xingheling.cn**（待部署）

---

## ✨ 功能特性

- **条目管理**：学期（8 个默认学期 + 自定义）、课程名称、学分、计算方式、成绩
- **计算方式联动**：百分制 → 整数输入框（0–100，拒绝小数）；五级制 → 下拉菜单（优秀/良好/中等/及格/不及格）
- **行内「计算 GP」**：单门课程绩点一键计算，保留 1 位小数
- **一键计算 GP**：所有课程批量计算，增量缓存——只算新增课程，已算的不重复计算
- **最高/最低 GP 统计**：按精确值比较（92 分与 93 分不会因四舍五入误判并列），并列课程顿号分隔
- **GPA 均绩计算**：多选一个或多个学期，加权汇总 GPA / 总学分 / 覆盖课程数
- **数据本地化**：「保存条目」下载数据文件到本地（文件名含时间戳与课程数）；导入上次文件即可恢复
- **进入保护**：首次使用弹免责声明（无关闭按钮，需明确同意）；计算 GPA 前强制提醒保存数据
- **移动端适配**：≤760px 自动单列布局，手机浏览器可直接使用

## 🧮 计算规则（北理工 4 分制）

| 类型 | 规则 |
| --- | --- |
| 百分制 X | X < 60 → GP = 0；60 ≤ X ≤ 100 → GP = 4 − 3 × (100 − X)² / 1600 |
| 五级制 Y | 优秀 4.0 / 良好 3.6 / 中等 2.8 / 及格 1.7 / 不及格 0.0 |
| GPA | GPA = Σ(学分 × GP) / Σ(学分) |

> GP 与 GPA 均保留 1 位小数；百分制成绩一律整数。

## 📦 数据格式

「保存条目」会下载一个 JSON 数据文件（文件名含保存时间与课程数），之后在任何设备上点击「导入上次数据」选择该文件即可恢复全部记录：

```json
{
  "version": 1,
  "entries": [
    { "id": "a1b2c3d4", "semester": "大一上", "course": "高等数学A",
      "credit": 5.5, "type": "percent", "score": 92 },
    { "id": "e5f6g7h8", "semester": "大一上", "course": "大学英语",
      "credit": 3.0, "type": "grade5", "grade": "优秀" }
  ],
  "semesters": ["大一上", "大一下", "大二上", "大二下"]
}
```
